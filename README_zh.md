# bililight

<a href="README.md">English</a>
<a href="README_zh.md">中文</a>

一个轻量化的第三方 Bilibili 网页客户端，旨在为手机、平板、手表等不同设备提供简洁的网页版 B 站浏览体验。项目由 Andy12 开发，loughead 立项，立项时间为 2025 年 12 月。

> **项目状态：部分基本功能均已实现。更多功能正在拓展。

## 项目目标

bililight 希望在浏览器中还原 B 站的核心浏览与互动体验，同时保持页面轻量、加载快速，并尽可能适配小屏幕与非传统设备（如智能手表）。项目不提供视频托管，所有内容均来自 Bilibili 官方服务，客户端仅作为前端展示与交互层。

## 预期功能

1. **视频观看与个性化推荐**：在线播放 B 站视频，并根据用户偏好提供推荐内容。
2. **Cloudflare 代理存储 JSON 数据**：使用 Cloudflare Workers 或 KV 存储部分非敏感的 JSON 数据（如缓存、配置），降低源站压力。
3. **账号登录与个人数据**：用户可登录自己的 B 站账号，登录后查看历史记录、收藏夹、稍后再看和消息中心。
4. **评论与互动**：支持在评论区留言、回复他人内容，以及一键三连（点赞、投币、收藏）。
5. **下载模块**：提供视频下载入口（具体实现方式取决于 B 站接口的可用性与合规性）。
6. **发布视频入口**：网站内提供“发布视频”按钮，跳转至 B 站官方创作中心。
7. **搜索功能**：支持搜索视频并展示结果列表。
8. **关注动态**：查看已关注 UP 主的动态更新。
9. **多端适配**：页面能够适配手机、平板、手表等不同尺寸与交互方式的设备。
10. **播放器控制**：播放视频时可调节倍速、画质、进度、字幕等参数。

## 技术方向

- **前端**：计划采用现代前端框架构建响应式界面，重点优化小屏幕下的布局与触控操作。
- **后端 / 代理层**：使用 Node.js 提供轻量 API 代理，处理 B 站公开接口的请求转发与必要的签名计算。
- **数据存储**：非敏感缓存与配置数据考虑使用 Cloudflare 提供的免费存储服务。
- **部署**：目标是在低配置服务器（如 1 核实例）上能够运行基础浏览功能，但登录与用户数据相关功能需要额外的资源与安全考量。

## 重要说明与限制

- **登录与用户数据**：B 站的登录、历史、收藏、评论、三连等功能依赖用户 Cookie 与私有接口。在第三方网页中处理真实账号登录存在**凭据泄露风险**，且 B 站风控可能拦截来自数据中心 IP 的登录请求。本项目在公开部署时**不应要求用户输入 B 站密码**，相关功能的可行实现方式仍在评估中。
- **接口稳定性**：B 站 Web API 存在签名机制（如 WBI 签名）与风控策略，接口可能随时变更。项目需要持续维护以跟进这些变化。
- **合规性**：项目应遵守 B 站的服务条款与相关法律法规，不提供侵犯版权或绕过付费墙的内容。下载功能的具体边界需谨慎界定。
- **当前状态**：如上所述，仓库尚未包含完整实现。任何尝试运行本项目代码的行为都应视为开发调试，而非可用的产品。
